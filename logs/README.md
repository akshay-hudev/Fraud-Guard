# Demo-application logs (not manuscript results)

These files are written by the legacy pipeline (`training/scripts/run_pipeline.py`), which trains the models
served by the demo API/dashboard on the legacy 2,100-claim dataset. That dataset is separable by construction
(see `paper/research_audit.md`, B-03), so near-perfect scores here say nothing about real-world performance.

Manuscript results are produced only by `research/` and stored in `results/` (see `research/README.md`).
Pre-remediation logs are archived, unverified, in `archive/legacy_unverified/`.
